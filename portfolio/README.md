---

## 📄 문서 목록

### 1. OS/DB 계정 신청서 상신/결재 Flow
- **내용**: 계정 신청 → 필수항목/중복/특수문자/파일 검증 → 상신 → 결재라인 생성 → 단계별 결재 → 계정 생성/변경/폐기
- **설계 포인트**:
  - 신청서·결재라인·자산·계정 이력 4개 그룹 테이블 설계 + ERD
  - 모든 테이블 적재 실패 시 전체 롤백 + 실패 알림
  - 결재 단계별 메일 발송(결재요청/결재완료), 재상신 케이스 처리
- **📄 [상세 요약 보기](./001_osdb-신규신청서-상신결재-flow/summary.public.md)**

### 2. 퇴사자 비밀유지 서약서 — 화면/테이블/RDB DATA FLOW
- **내용**: 퇴사자 NDA 징구 → 점검(4종 상태) → 계정 회수 → 복원까지 전 프로세스
- **설계 포인트**:
  - 점검상태 4종 자동 판정(파일 첨부 + 보안담당자 확인), 검색/메일/엑셀/파일첨부 관리자 기능
  - 서약서 테이블 + 이력 테이블(복제 구조) + 첨부파일 연계
  - 종료일 만료 배치 → 계정 회수 + 사후점검, 사후점검 메일 배치(14일 경과 시 보안담당자 알림)
  - 퇴사자 복원 신청 분기 처리, 배치 실패 로그/롤백
- **📄 [상세 요약 보기](./002_퇴사자-비밀유지서약서-화면-테이블-플로우/summary.public.md)**
