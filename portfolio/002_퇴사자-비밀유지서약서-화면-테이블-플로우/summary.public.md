## 📌 문서 내용 요약

**통합계정관리시스템(IAM)의 퇴사자 비밀유지 서약서(NDA) 기능** 설계 — 퇴사자 계정의 비밀유지 서약서 징구·점검·계정 회수까지 전 과정:

### 1) 화면 설계
- **그리드 컬럼**: 회사/사번/이름/부서명/부서코드/부서정상여부/부서장보/파일첨부여부/해지일자/경과일자/점검상태/통합ID복원신청여부/근거문서/신청자
- **점검상태 4종**: 이상없음 / 첨부대기 / 점검대기 / 첨부경과 (파일 첨부 유무 + 정보보안 담당자 확인 여부로 결정)
- **검색조건**: 사번/부서명/이름/부서정상여부/파일첨부여부/해지일자/해지경과일(1~3일 등)/점검상태/통합ID복원신청여부
- **관리자 기능**: 메일 발송(체크 대상자만), 엑셀 다운로드, 파일첨부 팝업(삭제 기능), 근거문서 더블클릭 → 이전 신청서 조회

### 2) 데이터 설계 (테이블)
- **비밀유지 서약서 테이블** (SECURITY_NDA_T(비밀유지 서약서) 계열):
  [사번](사번) / 부서코드 / 직군코드([직군코드]) / 해지일자([사번종료일자]=사번종료일자) / 수정자 / 적재일자 / 수정일자 / 점검상태([점검상태컬럼]) / STATUS([상태코드]) / 점검완료일자 / 통합ID복원신청여부(Y/N) + **임시저장여부([임시저장여부])·삭제여부([삭제여부])·신청서번호([신청서번호])**
- **이력(History) 테이블**: 변경 사유([변경사유])와 함께 전체 변경 내역 적재 (복제 구조)
- 연계: 사용자 테이블(USER_T(사용자)) 사번 PK, 부서 테이블(DEPT_T(부서)), 첨부파일 테이블(APL_FILE_ATTCH_T(첨부파일))

### 3) RDB 데이터 플로우 (프로세스별)
- **기타직 퇴사**: 해지 신청서 작성 → 상신자 부서장 결재 → 통제부서 담당자 결재(서약서 점검 팝업) → 최종결재 → 서약서 테이블 적재(임시저장 Y→N) / 반송·반려 시 이력 적재 + 데이터 삭제
- **종료일 만료 배치** ([퇴사자 만료 배치], [새벽 배치]): 만료 대상자 조회 → [만료 예정 알림 기준] → 계정 회수 + 사후점검 테이블 적재
- **사후점검 메일 배치**: 생성 기준 [사후점검 알림 기준] 경과 시 부서장·보안담당자에게 첨부대기 대상 메일, 14일 경과 시 정보보안 담당자 1회 메일
- **퇴사자 복원**: 신청서 상신 시 복원신청여부 Y → 최종결재 시 데이터 삭제 또는 복원 처리 (반려/반송 분기 포함)
- **첨부파일 업로드**: 화면 → Service에서 file SEQ 추출 → 첨부파일 테이블 insert → 서약서 테이블에 SEQ 적재 → 재조회
- **실패 처리**: 배치 성공/실패 로그 적재, 트랜잭션 롤백

### 4) 결정사항 (기획 메모)
- 기타직만 적용 (위계직/도급직은 추후 추가 방향)
- 메뉴 2개 추가 (일반 사용자/관리자), 사용자 이력은 사번 PK
- 메일 발송 조건 3안 (이상없음 포함/제외 여부) — 결정 필요 사항 정리

## 💡 이력서 활용 포인트

1. **증명하는 역량**:
   - IAM 퇴사자 관리 프로세스 (서약서 징구 → 점검 → 계정 회수 → 복원) — 계정 라이프사이클 전 영역 설계
   - **화면 + 테이블 + 데이터 플로우 3층 설계** — UI/DB/배치를 함께 설계하는 풀스택 능력
   - 배치 설계 ([만료 예정 알림 기준] 메일, 사후점검 [사후점검 알림 기준] 메일) — 이력서 "배치 67% 단축"과 연결
   - 상태 관리 설계 (점검상태 4종, Y/N/I/W, 임시저장/삭제 플래그) — 도메인 규칙 설계
   - 보안 프로세스 (비밀유지 서약, 정보보안 담당자 승인) — PCI DSS 대응 경험과 연결

2. **001과의 차별점**: 001은 신청서 상신/결재 흐름, 002는 **퇴사자/계정수명주기** — 둘이 합치면 IAM 계정 라이프사이클(입사→재직→퇴사→복원) 전체 설계 증명. 면접에서 "계정 수명주기 전체를 설계했다"는 강력한 스토리.

3. **활용 방법**: 001과 동일 — 포트폴리오(GitHub) + 면접 자료. 이력서에 "퇴사자 비밀유지 서약서 프로세스 설계 (점검 상태 관리 + 배치 자동화)" 1줄 추가 가능.
